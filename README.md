# introai_pr2
# Практическое занятие № 2

## Тема

Построение конвейера компьютерного зрения: детекция объектов и семантическая сегментация видеоряда.

## Студент

- ФИО: Соболева Елизавета Максимовна
- Поток: 1.2

## Цель работы

Познакомиться с готовыми инструментами компьютерного зрения для детекции объектов и сегментации изображения, а также реализовать полный цикл обработки видео: извлечение кадров, запуск моделей, визуализация результатов и создание анимированных GIF.

## План выполнения

- Установка и настройка ffmpeg, Miniconda и Python-окружения.
- Подготовка короткого видео.
- Извлечение кадров с помощью ffmpeg.
- Детекция объектов на кадрах.
- Сегментация объектов на кадрах.
- Визуализация результатов.
- Сборка двух GIF-анимаций.
- Сравнение детекции и сегментации.
