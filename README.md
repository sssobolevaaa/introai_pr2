### Установка Miniconda

Установлена Miniconda3 на Windows 10/11:

- Скачана с: https://docs.conda.io/en/latest/miniconda.html
- Установщик: `Miniconda3-latest-Windows-x86_64.exe`
- Папка установки: `C:\Users\<ты>\miniconda3`
- Тип установки: Just Me, без добавления в PATH.

Проверка выполнена в Anaconda Prompt:
```bash
conda --version
python --version
```
Версии:
- conda: <вставь версию>
- python: <вставь версию>

- ### Установка и проверка ffmpeg

Для обработки видеоматериала установлен ffmpeg на Windows.

Проверка выполнена командой:

```bash
ffmpeg -version
```

```text
ffmpeg version 9.0.2-essentials_build-www.gyan.dev
```

Команда выполняется корректно, поэтому ffmpeg успешно добавлен в PATH.
